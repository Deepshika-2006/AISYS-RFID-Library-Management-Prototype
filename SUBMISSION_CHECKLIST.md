- [ ] Run `pip install -r requirements.txt`
- [ ] Run `python manage.py migrate`
- [ ] Run `python manage.py seed_demo`
- [ ] Run `python manage.py test tests`
- [ ] Run `python manage.py runserver`
- [ ] Demonstrate AC01–AC08 live
- [ ] Prepare AC09/AC10 backup/rollback evidence
- [ ] Push the project to a private/public GitHub repository according to AISYS instructions
- [ ] Add README and presentation to the repository or email attachments
- [ ] Remove `.env`, passwords, tokens and real personal data
- [ ] Check that only synthetic data is included
- [ ] Replace the demo password before any real deployment
- [ ] Reply to the AISYS email before October 10, 2026 with the presentation and repository/supporting links
