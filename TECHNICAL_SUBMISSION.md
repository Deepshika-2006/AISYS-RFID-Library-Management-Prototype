# AISYS Technical Evaluation Submission

**Project:** RFID-enabled Library Management Extension
**Candidate prototype:** AISYS RFID Library

## Submission contents
- Runnable Django prototype
- Source code and migrations
- Synthetic sample data
- Controlled spreadsheet migration utility
- Mock RFID, security gate, smart-card and NCIP/SIP2 adapter boundaries
- Authentication, audit logs and health endpoint
- Reports/dashboard
- Requirements traceability, architecture, testing, deployment and rollback documentation
- Demonstration script and presentation

## Scope discipline
The AISYS assignment explicitly excludes physical manufacture/installation and access to production systems. Therefore this prototype demonstrates device-neutral interfaces and mocks rather than pretending to have access to vendor hardware or live institutional databases. See `docs/limitations.md` for production backlog.
